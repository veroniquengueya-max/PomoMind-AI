# 🦅 PomoMind AI - ICT University 2026

## 🇫🇷 1. Description du Projet
**PomoMind AI** est un écosystème d'étude multi-agent universitaire et bilingue (Français/Anglais) conçu pour optimiser l'apprentissage des étudiants de l'ICT University sans surcharger leur bande passante internet. Grâce à son **Agent Feynman**, il simplifie les concepts d'architecture et de cybersécurité complexes, propose un Chat IA sécurisé par empreinte SHA-256 et génère des certifications académiques dynamiques.

## 🇬🇧 2. Project Description
**PomoMind AI** is a bilingual (French/English) university multi-agent study ecosystem built to optimize student learning without overloading mobile data. Powered by the **Feynman Agent**, it simplifies complex architecture and cybersecurity concepts, features an SHA-256 secure AI Chat Hub, and generates dynamic academic certificates.

---

## 🤖 3. Architecture Multi-Agents / Multi-Agent Framework (Rule 6.3)
L'intelligence de notre système est divisée en **4 agents spécialisés** qui collaborent en temps réel :
1. **The Feynman Agent (Simplificateur) :** Ingests dense technical course materials and outputs simple, modular concepts using real-world analogies.
2. **The Translation Agent (Traducteur) :** Manages strict bilingual compliance (FR/EN) across the interface and outputs with a single click.
3. **The Token Optimizer Agent (Contrôleur) :** Compacts prompts and context sizes to preserve network bandwidth and minimize infrastructure costs.
4. **The Quiz Agent (Évaluateur) :** Automatically builds interactive recall flashcards and logs assimilation states.

---

## 📡 4. Technologies & Sponsors Integration (Rule 6.3 & 6.4)
- **NVIDIA Cloud AI (Nemotron Logic):** Serves as the core cognitive reasoning engine for our multi-agent text processing and layout definitions.
- **Zetaris (Data Harness Philosophy):** Implemented to simulate secure data virtualization, enabling real-time course streaming from the professor's hub to the student node without local file replication.
- **Meterless Token Probe:** Embedded logical probe tracking real-time input/output token metrics to enforce strict financial infrastructure cost control.

## 🚀 5. Setup, Dependencies & Launch
### Requirements
- Python 3.10+
- Streamlit
- Pillow (PIL)

### Installation
1. Clone the repository:
```bash
git clone https://github.com/veroniquengueya-max/PomoMind-AI.git
cd veroniquengueya-max
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application locally:
```bash
streamlit run app.py
```
